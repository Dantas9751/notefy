## Arquitetura

- **Um documento, um `data`.** O Design é `Document.kind = "design"`, como nota, planilha, diagrama e canvas: pasta, abas, split, lixeira, favoritos, modelos, busca, backup, duplicar e somente leitura vêm prontos. Nenhuma tabela nova.
- **Árvore, não lista.** Camadas aninhadas (`children`) como no Figma: um frame contém outros. Coordenadas **relativas ao pai**, então mover um frame move tudo dentro dele sem tocar nos filhos, e o HTML aninha do mesmo jeito.
- **Módulo puro + componentes finos.** Toda a regra mora em `frontend/src/lib/design.js` (sem React, testável com `node --test`): busca na árvore, mover entre pais, agrupar, alinhar, distribuir, restrições, CSS de cada camada. Os componentes só desenham e traduzem gestos em chamadas para ele.
- **Um desenhista para tudo.** `DesignNode` transforma uma camada em elemento com o CSS de `estiloDaCamada()`. A tela, a exportação (SVG com `foreignObject`, PNG a partir do SVG) e a aba "Código" usam a mesma função, então o que se vê é o que sai.
- **Medir no DOM, não adivinhar.** Com auto layout e texto que cresce sozinho, o tamanho real só existe depois do layout. A seleção, as alças e as guias leem `offsetLeft/offsetTop/offsetWidth/offsetHeight` (que ignoram `transform`), e o modelo continua a fonte da verdade do resto.
- **Desfazer e salvar** são os do `DocumentEditor` (`onChange` a cada quadro, `onCommit` no fim do gesto), como no canvas.
- **Imagens** sobem como anexo do documento (`/documents/upload/` com `attached_to`), igual à imagem colada no canvas; o backup e o "duplicar" já reescrevem os caminhos (`content/midia.py` troca no JSON inteiro).

## Formato de `data` (versão 1)

```jsonc
{
  "version": 1,
  "pages": [
    { "id": "p1", "name": "Página 1", "background": null, "children": [ /* camadas */ ] }
  ],
  "viewport": { "p1": { "x": 0, "y": 0, "zoom": 1 } }
}
```

Camada (todas):

| Campo | Tipo | Notas |
|---|---|---|
| `id` | texto | único no documento |
| `type` | `frame` `group` `rect` `ellipse` `line` `text` | |
| `name` | texto | nome no painel de camadas |
| `x` `y` `w` `h` | número | relativos ao pai; `w`,`h` ≥ 0 |
| `rotation` | graus | opcional |
| `opacity` | 0–1 | opcional |
| `visible` `locked` | bool | opcionais |
| `fills` | `Paint[]` | de baixo para cima |
| `strokes` | `Paint[]` | só `solid` |
| `strokeWidth` | número | |
| `strokeAlign` | `inside` `center` `outside` | |
| `radius` | número ou `[tl,tr,br,bl]` | |
| `effects` | `Effect[]` | |
| `constraints` | `{h: left/right/leftright/center/scale, v: top/bottom/topbottom/center/scale}` | ao redimensionar o pai |
| `sizing` | `{h, v}`: `fixed` `fill` `hug` | dentro de auto layout (e `hug` no próprio frame) |
| `absolute` | bool | ignora o auto layout do pai |

`Paint`: `{type:"solid", color:"#RRGGBB", opacity}` · `{type:"linear", angle, stops:[{at, color, opacity}]}` · `{type:"image", src, fit:"fill"|"fit"|"stretch"|"tile"}`; todos com `visible` opcional.

`Effect`: `{type:"drop"|"inner", x, y, blur, spread, color, opacity}` · `{type:"blur"|"bgblur", blur}`.

Por tipo:
- **frame**: `children`, `clip` (bool), `layout: {mode:"none"|"row"|"column", gap, padding:[t,r,b,l], align:"start"|"center"|"end"|"stretch", justify:"start"|"center"|"end"|"between", wrap}`.
- **group**: `children`. A caixa do grupo é sempre a união dos filhos (normalizada a cada mudança).
- **text**: `text`, `font: {family, size, weight, italic, lineHeight (multiplicador ou null), letterSpacing (px), align, valign, decoration, case}`, `autoSize: "width"|"height"|"fixed"`. A cor é o primeiro `fill`.
- **line**: comprimento em `w`, ângulo em `rotation`, cor e espessura em `strokes`/`strokeWidth`.
- **rect / ellipse**: só os campos comuns. Imagem é um retângulo com `fill` do tipo `image`, como no Figma.

**Laviel:** o tipo entra em `ROTULO_KIND`, então o pedido livre ("crie uma tela de login", "troque o botão para verde") já passa pela tarefa `editar`, que devolve o JSON inteiro e é validado por `validate_data`. O prompt ganha um resumo deste formato quando o item aberto é um Design.

Limites no servidor: 50 páginas, 5000 camadas, 40 níveis de profundidade.

## Interface (identidade do Notefy, mecânica do Figma)

- **Esquerda:** Páginas (lista recolhível) e Camadas (árvore com ícone por tipo, renomear com duplo clique, olho, cadeado, arrastar para reordenar ou mudar de pai).
- **Centro:** quadro infinito com a cor da página; frames do topo mostram o nome acima (clique no nome seleciona); seleção, alças, rotação, medida "W × H" e guias na cor de destaque do app (não o azul do Figma).
- **Barra flutuante embaixo:** Mover (V), Mão (H), Frame (F) com tamanhos prontos, Retângulo (R), Elipse (O), Linha (L), Texto (T), Imagem; zoom à direita.
- **Direita:** abas **Design** e **Código**. Design: alinhar/distribuir, posição e tamanho, auto layout, restrições, aparência (opacidade, raio), preenchimento, borda, efeitos, texto, exportar.
